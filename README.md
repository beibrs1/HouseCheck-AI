# HouseCheck AI 2.0

Десктопное приложение на Python/PySide6 для выбора жилых комплексов Астаны по отзывам жителей. Дизайн — по Figma-прототипу и стилю NGIJIH: тёплый светлый фон, оранжевый акцент, тёмно-синие панели, белые карточки с большими радиусами и мягкими тенями.

## Что нового в 2.0

- **Новый интерфейс**: главная с hero-блоком и статистикой, сетка карточек ЖК с обложками, кольцами индекса и рейтингом, плавающий лоток сравнения.
- **Анимации**: переходы между страницами, появление карточек «волной», анимированные кольца и шкалы, набегающие счётчики, плавная смена темы и языка, тосты-уведомления, hover-эффекты кнопок и карточек.
- **Поиск**: командная палитра `⌘K` / `Ctrl+K` (ЖК, разделы, вопрос помощнику), живой поиск и фильтры по району и классу, сортировка, режим цен «Покупка/Аренда».
- **ИИ-помощник Доми** — анимированный персонаж (моргает, следит за курсором, «думает» и «говорит»). Отвечает по данным приложения: подбор под профиль, лучшие по критерию, бюджет («до 35 млн»), районы, сравнение ЖК, сводка по конкретному ЖК с цитатой из отзывов. Если в `.env` указан `ANTHROPIC_API_KEY`, ответы формирует Claude по тем же данным; без ключа работает локальный режим.
- **Интерактивная карта Астаны**: пины по индексу комфорта, зум колесом, перетаскивание, подсказки.
- **Мой комфорт**: быстрые профили и живой топ-5, пересчитывающийся при движении слайдеров; персональный индекс «Для вас» в карточках.
- **Иконка приложения** с персонажем Доми, сборка через `HouseCheckAI.spec`.

## Что добавлено в 2.1

- **Регистрация** (имя, e-mail, логин, пароль и его повтор), вход по логину или почте, сообщение при неверном пароле.
- **Мой профиль**: личные данные, «Изменить профиль», «Сменить пароль», статистика действий.
- **Восстановление пароля**: «Забыли пароль?» → 6-значный код на почту (живёт 15 минут, 5 попыток, хранится только хеш) → новый пароль.
- **Аналитика**: итоговые показатели (среднее, медиана, σ, корреляция Пирсона), графики по районам, распределение оценок, точечный график «цена ↔ комфорт» с линией регрессии, таблица ЖК с фильтром и сортировкой.
- **Принятие решений**: метод взвешенной суммы (WSM) и TOPSIS по весам из «Мой комфорт», лучший ЖК, объяснение выбора и согласованность методов (ρ Спирмена).
- **Свои ИИ-функции**: анализ тональности отзывов, прогноз «справедливой» цены (регрессия), рекомендации, блок «Как ИИ пришёл к выводу» с уверенностью и ограничениями.
- **Почта**: отправка отчёта на e-mail через SMTP с понятными ошибками; без настроек письмо сохраняется в `data/outbox`.
- **Отчёты**: экспорт в PDF, HTML, CSV (Excel) и JSON.
- **История действий**: поиск, вопросы Доми, расчёты, отчёты и входы сохраняются в SQLite; поиск, фильтр по действию и периоду, экспорт CSV.
- **Проверка данных**: валидация ввода и импорта, проверка базы (`PRAGMA integrity_check`, оценки, координаты, ссылки) с автоисправлением.
- **Завершение сеанса**: «Выйти» возвращает к окну входа и очищает данные сеанса; автовыход через 30 минут бездействия.
- **Тесты**: `python -m unittest discover -s tests -t .` — 51 тест (база, расчёты, ИИ на трёх наборах данных, авторизация, почта, отчёты).

Соответствие требованиям по пунктам — в [docs/CRITERIA.md](docs/CRITERIA.md).

## Демо-режим для презентации

По умолчанию `HOUSECHECK_SEED_DEMO=1`: в базу добавляются 14 ЖК Астаны и ~130 **демонстрационных** отзывов. Они сохраняются с источником «Демо-данные» и так подписаны в интерфейсе, чтобы их нельзя было спутать с отзывами из Google Maps или импорта. Адреса, цены и координаты в демо-наборе ориентировочные. Для рабочего режима поставьте `HOUSECHECK_SEED_DEMO=0` — демо-отзывы будут удалены при запуске.

Десктопное приложение на Python/PySide6 для проверки жилых комплексов по отзывам жителей. Интерфейс собран по прототипу HouseCheck AI в Figma: каталог, карточка ЖК, карта, избранное, сравнение, профиль комфорта и ИИ-помощник. Текущий каталог ограничен городом Астана.

## Запуск на macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
python main.py
```

Если на компьютере уже есть подготовленная среда проекта:

```bash
source .venv-fast/bin/activate
python main.py
```

Первый вход: `super_admin` / `super_admin`.

## Карта и реальные отзывы Google Maps

Ключ хранится только локально в `.env`:

```env
GOOGLE_MAPS_API_KEY=ваш_Maps_Demo_Key
GOOGLE_PLACES_API_KEY=ваш_Places_API_Key
```

Кнопка «Открыть в Google Maps» использует официальный Google Maps URL и работает без ключа. Для загрузки реальных отзывов в карточке ЖК нажми «Обновить отзывы Google».

Для этой кнопки нужен `GOOGLE_PLACES_API_KEY`: включи Places API (New) в Google Cloud, создай ключ и подключи биллинг Google Cloud. Приложение сохраняет в SQLite только полученные данные и показывает источник каждого отзыва. Если ключ не задан, приложение не подставляет демо-тексты и честно показывает «Нет данных».

## Импорт отзывов

Кнопка «Импорт отзывов» принимает JSON такого вида:

```json
[
  {
    "name": "Название ЖК",
    "city": "Алматы",
    "district": "Медеуский район",
    "address": "ул. Примерная, 1",
    "lat": 43.238,
    "lng": 76.945,
    "deal_type": "Покупка",
    "price_from": 50000000,
    "reviews": [
      {
        "source": "2GIS",
        "rating": 5,
        "author": "Анонимный пользователь",
        "text": "Тихий двор, рядом транспорт",
        "published_at": "2026-10-01"
      }
    ]
  }
]
```

База SQLite создаётся автоматически в `data/housecheck.sqlite3` (в собранном приложении — в папке данных пользователя). Режим демо-данных описан выше.

## Тема, язык и роли

- тема: светлая, тёмная или системная;
- язык интерфейса: русский, қазақша, English;
- роли: `viewer`, `analyst`, `editor`, `super_admin`;
- `super_admin` имеет все права и может создавать пользователей, менять пароли и удалять пользователей;
- пароли хранятся в базе только как salted PBKDF2-SHA256 хеши.

## Windows

Исходный проект запускается на Windows теми же Python-файлами и SQLite-базой. Сборку `.exe` нужно выполнять на Windows:

```bat
build_windows.bat
```

Результат появится в `dist\HouseCheckAI\HouseCheckAI.exe`. Для macOS используется `build_macos.sh`. Обе сборки используют `HouseCheckAI.spec` (иконка, стили, ресурсы). Один и тот же exe-файл нельзя собрать на macOS и корректно использовать как Windows-приложение — PyInstaller собирает под текущую операционную систему.

На macOS после сборки автономное приложение находится в `dist/HouseCheckAI.app` и открывается двойным кликом. Оно хранит SQLite в системной папке данных пользователя, поэтому исходники и среда разработки для запуска не нужны.
